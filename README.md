# Sohum Mehta's portfolio site

The one-page site lives in `index.html` and has no build step. Open it directly or serve this folder with any static server. GitHub Pages publishes `main` to https://sohmeh.github.io.

Files the page links to:

- `resume.pdf`: the current resume. Replace it whenever the resume changes.
- `foto-pitch.pdf`: the Foto pitch deck.
- `foto-logo.svg` and `promptonium-logo.png`: the logos on the project cards.
- `sohum-picture.png`: the portrait at the top of the page.

The older design explorations remain untouched under `.superpowers/brainstorm/`.
